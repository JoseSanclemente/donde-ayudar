# Fuente: recopilación ciudadana (reportes, medios y organismos de socorro).
# No es un censo ni un dato oficial. De acá salen las zonas del mapa, nunca un
# punto por dirección: `scripts/build-affected-zones.mjs` funde las cercanas.
#
# Una entrada por línea, campos separados por «|»:
#
#   código | dirección | colapso|afectacion | sector | lat,lng
#
# El sector es opcional y se escribe a mano — el script no lo deduce. La
# coordenada también es opcional y, cuando está, se salta la geocodificación:
# es para lo que la nomenclatura no resuelve. Las líneas que empiezan con # se
# ignoran, y lo que va después de un # en una línea con datos es un comentario.
#
# Las esquinas van en forma canónica —«Carrera 44 # 5-0», cero metros desde el
# cruce— y no como «Carrera 44 con Calle 5ta»: `parseAddress` no tiene rama para
# «con», y sin placa el cruce entero cae en `rest` y la dirección se resuelve al
# punto medio de la vía en toda la ciudad.
